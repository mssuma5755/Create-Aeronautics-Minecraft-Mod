## 📦 Overview

The Create Aeronautics mod adds advanced physics and aerial machinery to Minecraft. You can design flying machines, hot air balloons, and complex airships. This mod works with the NeoForge mod loader on version 1.21.1. It provides tools to build vehicles that move through the air with fluid physics and mechanical power.

## ⚙️ System Requirements

Before you install the mod, check your computer against these requirements. Running modded Minecraft requires more memory than the standard game.

- Operating System: Windows 10 or 11
- Processor: Intel Core i5 or AMD Ryzen 5
- Memory: 8 GB RAM (16 GB recommended)
- Graphics Card: NVIDIA GTX 1660 or equivalent
- Disk Space: 500 MB for mod files
- Java: Java 21 (required for Minecraft 1.21.1)

## 🛠️ Installation Steps

Follow these steps to set up the mod on your Windows computer.

1. Install the latest version of NeoForge for Minecraft 1.21.1 from the official website.
2. Run the NeoForge installer. Select the "Install Client" option.
3. Open the Minecraft Launcher.
4. Select the NeoForge profile you created in the installation steps.
5. Click "Play" to start the game one time. This creates the necessary game files on your drive.
6. Close the game after the title screen loads.
7. Press the Windows key and R on your keyboard.
8. Type `%appdata%` in the box and press Enter.
9. Open the folder named `.minecraft`.
10. Open the folder named `mods`. If you do not see a folder named `mods`, create one.
11. Move the `.jar` file you downloaded into the `mods` folder.
12. Launch the Minecraft Launcher again and start your NeoForge profile.

## 🏗️ Building Your First Airship

Once the game starts, create a new creative mode world to test the mechanics. The mod includes new blocks for building. 

- Propeller Bearings: Use these to rotate your ship parts.
- Aeronautics Chassis: Connect these blocks to form the frame of your airship.
- Boiler Engines: Generate mechanical power to run your propellers.

Place a control interface on your structure. Right-click the interface to enter pilot mode. Use your keyboard controls to steer your vehicle through the air. Start with a small platform to learn how the physics work.

## 🔍 Troubleshooting Common Issues

If the game crashes or the mod does not load, try these solutions.

- Check the file compatibility: Ensure your downloaded file matches the game version 1.21.1.
- Clear the cache: If you have old mod files, move them out of the `mods` folder.
- Update Java: Ensure your machine runs the latest version of Java required for the Minecraft version.
- Check logs: Look inside the `logs` folder within your `.minecraft` directory. Open the `latest.log` file in a text editor to see error messages.
- Memory settings: Open the Minecraft Launcher, go to Installations, click your profile, click More Options, and increase the JVM argument `-Xmx` to at least 4G or 6G.

## 📈 Performance Tips

The mod performs physics calculations for every flying vehicle. If your frame rate drops, adjust your game settings.

- Turn down Render Distance: Lowering this in Video Settings reduces the number of entities the computer tracks.
- Disable fancy graphics: High-quality shadows and lighting affect performance. Use fast graphics instead.
- Limit max frame rate: Set a fixed frame rate in the Video Settings menu to keep the game smooth.
- Close background apps: Web browsers and other programs consume memory that the game needs.

## 📜 Frequently Asked Questions

Does this mod work on multiplayer servers?
Yes, but the server administrator must install the mod on the server side as well. If the server does not have the mod, you cannot join with it active.

Can I use this with other mods?
This mod works with most standard forge mods. If you experience conflicts, remove other mods to test for stability.

Where do I report bugs?
If you find an error, look for the 'Issues' tab on the GitHub repository. Provide your log files to help the developers fix the problem.

Is there a Fabric version?
The project maintains a primary focus on NeoForge. See the repository topics for information on other supported loaders.

How do move my airship?
You must place a ship helm or steering wheel on your build. Interact with this block while holding the crouch key to assemble the ship. Once assembled, you provide power to the propellers to move.

Can I sink my airship?
The mod features physics that account for weight and buoyancy. If you build a ship that is too heavy or lack sufficient lift, it will not stay in the air. Use balloons to increase your buoyancy.

How do I add more fuel?
Boilers require water and fuel, such as coal or wood. Place a water pipe connected to the boiler and a funnel to feed fuel into the system.
